# Queensland Road Crash Intelligence

Power BI dashboard analysing 262K+ road crash incidents across Queensland (2001–2024) to identify severity patterns and high-risk factors.



## Key Findings

* Single vehicle crashes have a fatality rate 3x higher than other types
* Sunday nights record the highest average severity index (3.38)
* Very Remote areas have severity index of 3.8 vs 2.8 in Major Cities
* High speed zones (≥100 km/h) account for 46% of hospitalisations
* COVID-19 lockdowns caused a visible dip in 2020, volumes rising since



## Tools Used

Power BI Desktop, Power Query, DAX

[Queensland Government Open Data Portal](https://www.data.qld.gov.au/) — Road Crash Data (CC BY 4.0)
